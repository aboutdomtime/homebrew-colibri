# Homebrew Tap for colibri

Personal Homebrew tap for [JustVugg/colibri](https://github.com/JustVugg/colibri).

## Install

```sh
brew install aboutdomtime/colibri/colibri
```

Seeded from upstream release `v1.0.0`.

## Updating

`.github/workflows/update-formula.yml` checks the latest upstream GitHub release on a schedule and commits formula updates when a new release is available.
